# Changelog

All notable changes to **SocialCentral** are documented in this file.
Versioning follows Semantic Versioning (`MAJOR.MINOR.PATCH`). Ongoing development changes stay under `[Unreleased]` without altering the published version number until an explicit public GitHub release is requested (`PATCH`: `0.X.Y` -> `0.X.(Y+1)`).
