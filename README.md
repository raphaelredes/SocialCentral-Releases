Unified social, community, guild, LFG, world buffs, alts inventory, and compliant watchlist suite built exclusively for **World of Warcraft: Forever** (`Interface: 16001`).

## Features
- **Native Integration Across Official WoW Windows (`O`, `I`, `J`, `C`, `M`):** Docks cleanly via native side-tabs inside **Social (`O`)** (Watchlist, Social, Friendly Nearby, Conversations, Group), **Group Finder (`I`)** (unified Official LFG Tab 1 auto-mirror + Network Browser with bottom bridge bar, role recommendations, and native-tab isolation), **Guild (`J`)** (Hero overview, Roster + compact History, Events & Calendar with mutually authorized Allied sharing, Diplomacy, Professions & Lockouts), **Character (`C`)** (2D Equipment/Bags/Bank, Items Grid/List, Right-Side Dossier, Account Comparison Matrix, and seamless 2-press `C` toggle), and **World Map (`M`)** (minimalist pins & corner summary badge), with optional first-time per-shortcut auto-open prompts, safe protected-frame isolation, and explicit confirmation dialogs before any destructive action.
- **Unified Friends Directory & Friend Online Alerts:** Unites online & offline **WoW Character Friends**, **Battle.net Friends** (WoW Forever, other realms/games, Launcher/App & Offline), and online **Guildmates** in one deduplicated view with Favorites (`*`), per-player **Notification Bell / Muted Bell** icons and direct action controls on every name in window `O`, Social Folders, Linked Alts, Source/Folder/Offline filters, Smart/Name/Level/Last Seen sorting, Pending Battle.net Invite Accept/Decline banner, combat-safe `+ Friend` / Remove Friend modals, native WoW & Battle.net Friend Note editing, privacy-safe `lastSeen` (never saving BattleTag or Real ID), and configurable **Friend Online Alerts** (enabled for All Friends by default with Toast + optional sound & clickable chat link, 8s login grace, and 120s anti-spam cooldown).
- **Animated Chat-Colored Message Previews, Movable 3-Row Stack & Prismatic Fusion Counters:** Receive animated, 100%-opaque message previews with sender portraits and opening words tinted in authentic WoW chat colors (**Whisper Pink**, **Battle.net Cyan**, **Group Blue**, **Raid Orange**, **Guild Green**, **Private Room Violet**), stacked up to 3 simultaneous rows with FIFO queue (`+N`), 6s default countdown, interactive first-time channel/dungeon/raid/combat setup modal, and **free drag repositioning anywhere on screen** (drag any live preview or toggle the 3-slot visual placement guide via Settings or `/sc preview move`) while always launching from and flying smoothly back into the SocialCentral minimap icon; unread counters scale automatically to at least WoW's chat font size (`>= 14–15pt`) across the minimap, side-tabs (`O`, `I`, `J`), and Conversations, and feature the **Prismatic Multi-Color Fusion Circle** directly under the minimap icon (orbiting cleanly without overlap on arrival and hover, then spiraling into a swirling multi-color orb, with optional permanent separate orbital mode in Settings).

- **Compliant Watchlist (`/who`), Battle.net Account Tracking & Accurate Multi-Alt Sync:** Track characters (`FirstName Surname`) or whole **Battle.net friend accounts (All Alts)** via the Watchlist picker, inline suggestions, or Social right-click menus with privacy-safe session observation (never persisting BattleTags or Real IDs), automatic Guild/Friends sync, stale-online expiry (`Unchecked`), Battle.net active-character sibling suppression, disconnected party-member filtering, whisper offline bounce sync, smart `/who` cooldown conservation, Favorites (`*`), 1-click Verify Next / inline Check buttons, online chat/sound alerts, combat/popup guards, and strictly isolated hardware-event `/who` queries (`>= 5s` cooldown) that never pop open `Procurando grupo`.

## Slash Commands
- `/sc` or `/socialcentral` — Toggle main window
- `/sc chat` / `/sc group` / `/sc clan` — Jump directly to Conversations, Group, or Clan tab
- `/sc add <Name[-Surname]>` — Add a character to your Watchlist
- `/sc check <Name[-Surname]>` (or `/sc who <Name>`) — Add (if new) and run one safe `/who` check outside combat
- `/sc check` — Check the oldest Watchlist entry
- `/sc update` — Open GitHub Releases / Updater link modal
- `/sc preview [whisper|bnet|group|guild|queue|badge fusion|move|resetpos|setup|clear]` — Test message previews, fusion badge, or reposition the 3-row preview stack
- `/sc config` — Open SocialCentral Settings

## Updating via Public GitHub Releases
In-game DBM-style peer detection notifies you in chat if a friend/guildmate runs a newer released version, with a clickable link to our public releases repo (`raphaelredes/SocialCentral-Releases`).
On Windows, you can check GitHub and install the latest verified `.zip` automatically:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\update-socialcentral.ps1
```
